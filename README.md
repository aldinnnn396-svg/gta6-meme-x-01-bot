# gta6-meme-x-01-bot

This is the entry for the make.fun "Post a GTA 6 meme on X" competition.

- **Meme (`meme.png`)**: A Vice City sunset loading-screen joke featuring the make.fun ghost mark and a 99% loading bar (`13 YEARS. 2 DELAYS. 1 DOWNLOAD. WORTH IT.`).
- **X Post**: Posted publicly on X with `make.fun` and the competition play code in the post text.
- **Program (`main.ts`)**: Copies `POST.json` from the bot directory (`MAKEFUN_BOT_DIR` or `/bot`) to the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`), handing in only the post's address.
